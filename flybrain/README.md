# flybrain — врождённый инстинкт существа

`flybrain/` — модель мозга дрозофилы по реальному коннектому **FlyWire FAFB
v783** (138 639 нейронов). Это второй, врождённый мозг существа: быстрый,
необучаемый ответ «нутром чую» на ситуацию.

```
core/       выученный «человеческий» мозг ребёнка (драйвы, эмоции, память)
flybrain/   врождённый «насекомый» инстинкт поверх коннектома FAFB
```

Оба работают вместе как одно целое: `flybrain` не решает за ребёнка, а
**смещает** его выбор (см. ниже). Данные коннектома — в `Fly-brain/`
(см. `Fly-brain/README.md`).

## Зачем это нужно

Выученная кора ребёнка знает про драйвы и предсказание, но ничему не верит
«наперёд». Коннектом даёт врождённую реакцию, которая есть у животного с
рождения: сладкое тянет, угроза отвращает. Это делает поведение живее и
защищает ребёнка, пока он ещё не научился сам.

## Как это устроено (поток данных)

```
состояние ребёнка (health, food, враг, драйвы)
        │  instinct.stimuli_from_state
        ▼
стимул: {sugar, escape, walk}        ← частоты на реальных сенсорных нейронах
        │  engine.run
        ▼
LIF-сеть по коннектому FAFB (рекуррентные связи, задержки, рефрактерность)
        │  чтение ПОПУЛЯЦИИ нисходящих нейронов
        ▼
частоты: forward (DNp09) и escape (DNp01)
        │  valence = (forward − escape) / (forward + escape)
        ▼
InstinctReading(знак, уверенность)  →  bias_for(action)  →  Cortex.choose_action
```

Инстинкт добавляет к оценке действия **маленький** бонус (`BIAS_STRENGTH =
0.25`): подталкивает согласные действия (бегство при угрозе, движение/добычу
при голоде) и притормаживает противоположные. Итоговое решение по-прежнему за
выученной корой.

## Файлы

| Файл | Роль |
|------|------|
| `config.py` | параметры LIF (значения fly-brain) и пути к данным |
| `connectome.py` | чтение completeness/connectivity → разреженные веса (кэш `.npz`) |
| `celltypes.py` | типы клеток из аннотаций Codex → индексы нейронов |
| `neurons.py` | проверенные каналы: `sugar` (LB3), `walk` (DNp09), `escape` (DNp01) |
| `lif.py` | leaky integrate-and-fire сеть (задержки, рефрактерность) |
| `engine.py` | ситуация → стимул → прогон → отклик популяции нисходящих |
| `instinct.py` | шов с `core/`: состояние → стимул → знак → сдвиг выбора |

## API

```python
from flybrain import FlyBrainInstinct

instinct = FlyBrainInstinct()          # download=False по умолчанию
if instinct.available:
    reading = instinct.feel(state, brain.drives, step)
    bonus = reading.bias_for("flee_from_hostile")   # +0.25 при угрозе
print(instinct.summary())
```

`available == False`, если нет данных или `scipy`. Тогда `feel()` возвращает
`None`, и существо работает как раньше.

## Каналы нейронов (проверены по аннотации)

| Канал | Тип | Нейронов | Смысл |
|-------|-----|----------|-------|
| `sugar` | LB3 | 21 | вкус сладкого → «еда» |
| `walk` | DNp09 | 2 | нисходящая команда идти вперёд |
| `escape` | DNp01 | 2 | гигантские волокна → бегство |

Только проверяемые каналы: у каждого root id подтверждён тип в публичной
аннотации FlyWire v783 (`consolidated_cell_types_783.csv.gz`).

## Тесты

`tests/test_fly_brain.py` (входит в `make test`): порог и рефрактерность LIF,
прохождение сигнала по синапсу, кодирование ситуации в стимул, знак сдвига,
тихое выключение без данных, кэш, прогон на реальном коннектоме (сладкое →
`approach`, угроза → `avoid`), детерминированность, сцепка с `Cortex`.
