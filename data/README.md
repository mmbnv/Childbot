# data/ — состояние существа

Здесь мозг хранит всё, что помнит между перезапусками. Папка создаётся
автоматически при первом запуске, содержимое — рантайм и в git не попадает
(см. `.gitignore`).

| Файл | Что хранит |
|------|------------|
| `memory.json` | семантическая карта мира: посещённые клетки, опасные зоны, чёрный список, позиции игроков |
| `episodes.json` | автобиография — события с эмоциональной окраской |
| `self.json` | «Я»: тело, нарратив, метакогниция, самооценка |
| `neuromodulators.json` | химия: дофамин, серотонин, кортизол, окситоцин, … |
| `neural_predictor.npz` | веса кортикальной колонны |
| `relief_table.json` | быстрая память «действие → облегчение» |
| `skills.json` | навыки (имя, шаги, предусловия) |
| `knowledge.json` | выученные закономерности (фраза → действие) |
| `learned_intents.json` | выученные команды папы |
| `learned_rules.json` | правила подготовки к действиям и история сбоев |
| `goals.json` | история целей (последние 100) |
| `conversation.json` | недавний разговор |
| `cognition.json` | символическая память: объекты, эффекты, места |

Удалить всю память существа: `make clean` (или `rm -rf data/`).
