# Живое существо (цифровой ребёнок)

Существо, которое живёт в Minecraft. У него есть тело (`bot.js`) и мозг
(`core/`). Мозг устроен по принципам человеческого: потребности, эмоции,
внимание, память, предсказание и обучение.

## Запуск

```bash
pip install -r requirements.txt

# 1. тело (нужен сервер Minecraft; хост/порт в начале bot.js)
node bot.js

# 2. мозг
python run.py

# проверить мозг без Minecraft — искусственное тело
python run.py --mock
```

LLM (Ollama `qwen2.5:3b`) необязательна: без неё существо думает простыми
мыслями и понимает команды по словам-подсказкам.

## Структура

```
bot.js        тело (Node.js + mineflayer), HTTP API на localhost:3000
run.py        запуск мозга
core/         мозг: драйвы, эмоции, внимание, память, предсказание, обучение
flybrain/     врождённый инстинкт: модель мозга дрозофилы (коннектом FlyWire FAFB)
adapters/     тела для мозга: minecraft.py (реальное) и mock.py (для тестов)
tests/        проверки без Minecraft
data/         состояние существа (создаётся само, в git не хранится)
Fly-brain/    данные коннектома FAFB (качаются отдельно, в git не хранятся)
```

## Тесты

```bash
make test              # компиляция + все тесты
python tests/run_all.py
python run.py --mock --steps=100   # прогон на искусственном теле
```

Проверяются: обучение и разреженность нейроколонны, предсказание, внимание,
рабочая память, эпизоды, драйвы, планировщик, выход из ямы, речь и имитация.

## Как работает «мозг как у человека»

Каждый тик существо проходит цикл, повторяющий логику живого мозга:

1. **Ощущение.** Сенсоры: тело, зрение, звуки, речь папы.
2. **Гомеостаз.** Растут и падают потребности: голод, страх, боль,
   одиночество, усталость, скука, любопытство. Их сумма — *напряжение*,
   которое заставляет действовать (`core/drives.py`).
3. **Химия и эмоции.** Дофамин, серотонин, норадреналин, кортизол, окситоцин
   окрашивают всё. Из их сочетания рождается эмоция — «чувство»
   (`core/neuromodulators.py`).
4. **Внимание.** Сигналы конкурируют за значимость. Победитель попадает в
   глобальное рабочее пространство и осознаётся. В каждый момент существо
   осознаёт ровно одну вещь — самую важную (`core/global_workspace.py`).
5. **Рабочая память.** Удерживается цель, текущая мысль, фокус внимания —
   примерно 7 слотов, слабое забывается (`core/working_memory.py`).
6. **Предсказание.** Мозг «примеряет» действия в уме: «если сделаю X, станет
   ли легче?». Работают вместе кортикальная колонна (обобщение) и быстрая
   память (надёжный факт) (`core/predictor.py`, `core/neural_column.py`).
7. **Решение.** План строится мысленной симуляцией цепочек действий; иначе —
   спонтанное желание или привычный выбор с учётом уверенности в себе
   (`core/planner.py`, `core/cortex.py`, `core/autonomy.py`).
8. **Действие.** Моторная команда уходит телу через адаптер.
9. **Обучение.** Ошибка предсказания учит колонну (дофамин). Навыки и правила
   запоминаются (`core/learner.py`, `core/knowledge.py`).
10. **Память.** Событие записывается в автобиографию с эмоциональной окраской
    (`core/episodic_memory.py`).
11. **Сон.** При сильной усталости существо спит: повторяет опыт, уплотняет и
    чистит память (`Brain._consolidate`).

## Ремесло и рост

Существо не просто бегает и прыгает — оно учится делать вещи и умнеет шаг за
шагом, как ребёнок.

- **Рецепты.** `core/recipes.py` знает, из чего что делается, и умеет
  разложить цель на сырьё: для каменной кирки нужно дерево → доски → палки →
  верстак → деревянная кирка → камень → кирка.
- **Учебная программа.** `core/curriculum.py` — 28 ступеней роста: добыть
  дерево, сделать верстак, кирку, камень, печь, переплавить железо, броню,
  кровать, лук. Прогресс сохраняется, поэтому существо умнеет не за один день.
  Когда ступени пройдены, начинается бесконечный режим: существо поддерживает
  снаряжение и запасы — всегда есть чему учиться и что улучшать.
- **Умение.** `core/crafting.py` не выполняет жёсткий список, а перед каждым
  шагом смотрит в инвентарь и делает ровно то, чего не хватает прямо сейчас.
  Так работают настоящие выходы крафта (1 бревно → 4 доски) и инструменты.
- **Когда учится.** Ремесло идёт, когда существо сыто, не в сильной боли и
  рядом нет угрозы. Голод, драка и боль всегда важнее.

В теле (`bot.js`) это настоящие действия Minecraft: `gather` (добыть блок по
названию), `craft` (`bot.craft`, верстак при необходимости), `place_table`,
`smelt` (печь, `bot.openFurnace`).

## Любая игра, а не только Minecraft

Minecraft — не единственная игра. Существо устроено так, чтобы понимать
**фундаментальные понятия жизни** и справляться с тем, что ставит перед ним
любая другая игра.

- **Законы мира.** `core/concepts.py` наблюдает за своими действиями и
  выводит общие законы: *гравитация* (нет опоры — падаю вниз), *опора*
  (твёрдое держит), *стена* (сквозь твёрдое не пройти), *проход* (дверь можно
  открыть и она пропускает), *инструмент* (без нужного инструмента вещь не
  добыть), *соединение* (два вещества вместе дают новое), *плавка* (огонь
  меняет вещество), *опасность*, *питание*, *достижимость*. Законы выводятся
  из **признаков** (есть ли опора, сдвинулся ли, открылась ли дверь), а не из
  названий блоков — поэтому переносятся в любую игру.
- **Любопытство.** `core/experiment.py` ставит безопасные опыты, чтобы
  проверить непонятный закон: «прыгну и посмотрю, потянет ли вниз». Это
  делает существо исследователем, а не исполнителем.
- **Задачи игры.** `core/tasks.py` спрашивает у игры, чего она хочет
  (достижения, квесты, цели уровня), и выполняет их своими умениями. Если
  задача не про рецепт (открыть дверь, соединить ключ с замком, дойти до
  выхода) — существо выводит нужное действие из смысла задачи.
- **Другая игра — без правок.** `adapters/game2.py` — второе тело
  (подземелье: комната, ключ, дверь, выход), написанное специально, чтобы
  доказать универсальность: **тот же мозг** проходит и его, ничего о нём не
  зная.

## Врождённый инстинкт: мозг дрозофилы (fly-brain)

У существа есть не только выученный «человеческий» мозг (`core/`), но и
**врождённый инстинкт** — модель мозга дрозофилы по реальному коннектому
**FlyWire FAFB v783** (138 639 нейронов). Это быстрый, необучаемый ответ
«нутром чую», который дополняет выученное решение, а не заменяет его.

- **Что это.** `flybrain/` прогоняет короткий такт LIF-сети по коннектому:
  ситуация кодируется как стимул на настоящих сенсорных нейронах (вкус
  сладкого `LB3`), а отклик читается с нисходящих нейронов (ходьба `DNp09`,
  бегство `DNp01`). Отношение «вперёд / бегство» даёт врождённый знак.
- **Как влияет.** Инстинкт даёт **маленький** сдвиг к оценке действия
  (`BIAS_STRENGTH = 0.25`): при угрозе подталкивает бегство, при голоде —
  движение и добычу. Решение всё равно принимает выученная кора; инстинкт —
  лишь совещательный голос. Сильный порыв попадает в глобальное рабочее
  пространство — существо «осознаёт» его наравне с другими сигналами.
- **Необязателен.** Нет данных коннектома или нет `scipy` — инстинкт тихо
  выключается (`available == False`), и существо работает как раньше.

Данные (сотни МБ) в git не хранятся — их кладут в `Fly-brain/`
(см. `Fly-brain/README.md`). В `run.py` состояние инстинкта видно строкой
`🪰 инстинкт fly-brain: тянет/отвращает ...`. Подробности — в
`flybrain/README.md` и `AGENTS.md`.

## Причинно-следственное мышление

Когда что-то не выходит, существо не залипает — оно спрашивает **«почему?»**.

- **Разбор причины.** `core/causality.py` превращает неудачу в причину:
  *не дотянулся*, *нужен инструмент*, *стена*, *нет опоры*, *заперто*,
  *нет материала*, *не нашёл*, *нужна печь или топливо*, *далеко*.
- **Память причин.** Причина запоминается (сколько раз, что помогало). Так
  рождается убеждение: «в этом мире камень не бьётся без кирки». Убеждения
  переживают перезапуск (`data/causes.json`).
- **Размышление.** Из причины выводится средство: чего не хватает и как
  попробовать иначе — подойти ближе, обойти, прыгнуть, поставить опору,
  скрафтить инструмент, соединить ключ с замком.
- **Проверка.** Средство пробуется на деле. Помогло — причина помечается
  решённой, и в следующий раз существо действует сразу правильно.
- **Универсальность.** Причина — это связь «не вышло, потому что X; чтобы
  вышло — Y», а не имя блока. Поэтому одни и те же причины лечатся в любой
  игре: «заперто» — соединением, «нужен инструмент» — крафтом.
- **Проверка дела, а не слова.** Тело может ответить «получилось», а вещь не
  появиться (нет нужного блока рядом, добылся не тот предмет). Тогда существо
  замечает застой, называет причину *«говорят готово, а вещи нет»* и идёт
  искать дальше — вместо того чтобы долбить одно место бесконечно.
- **Материалы одного рода — взаимозаменяемы.** Любое дерево считается деревом:
  если в мире есть только берёза, ребёнок всё равно делает доски, палки и
  верстак, а не застревает на «нужен дуб».

Спросите ребёнка «почему?» — и он расскажет, что понял: *«папа, я понял:
заперто, нужно ключ. Придумаю, как иначе»*.

```bash
python run.py --mock          # песочница (Minecraft-подобная)
python run.py --game2         # другая игра: подземелье с ключом и дверью
```

Чем чаще существо играет, тем больше законов понимает и тем увереннее ведёт
себя в новой, незнакомой игре.

## «Я» и другие

- **Самосознание.** Существо знает своё тело, историю о себе и то, в чём оно
  уверено, а в чём нет (`core/self_model.py`).
- **Привязанность.** Игрок — «папа». Близость снижает одиночество и поднимает
  окситоцин.
- **Речь и имитация.** Понимает команды, учится новым словам, повторяет
  действия папы (`core/adaptive_intent.py`, `Brain.imitate_player`).

## Живое существо, а не робот: как устроен человек

Раньше это был «робот, который выполняет действия по коду». Теперь поверх
нужд и ремесла работает **человеческое ядро** — то, что делает поведение
живым, а не вычисленным. Ниже — из чего оно состоит и почему каждое решение
окрашено чувством.

### 1. Характер (`core/temperament.py`)

Существо **рождается** с характером — как человек. Пять черт («Большая
пятёрка») задают его на всю жизнь и красят всё остальное:

| Черта | Что определяет |
|-------|----------------|
| открытость новому | тяга исследовать, воображение |
| усидчивость | доводить дело до конца, терпение |
| общительность | тяга к папе, разговорчивость |
| доброжелательность | привязанность, эмпатия |
| впечатлительность | сила чувств, скорость усталости |

Характер сохраняется: существо остаётся собой между запусками. От него
считаются базовый «дофамин», порог страха, скорость привязанности и т.д.

### 2. Тело изнутри (`core/interoception.py`)

Прежде чем почувствовать, существо **ощущает себя**: «пусто в животе», «сердце
колотится», «щемит в груди», «зябко», «жарко». Это интероцепция — телесное
чувство, из которого (как учил Джеймс-Ланге) рождается эмоция. Состояние —
это переживание, а не числа.

### 3. Чувства (`core/emotions.py`)

Эмоция рождается не из «стимул → ответ», а из **оценки** того, что событие
значит для моих нужд («appraisal»). Отсюда — разные чувства:

| Оценка | Чувство |
|--------|---------|
| случилось желаемое | радость |
| потерял важное, ничего не поделать | печаль |
| угроза | страх |
| мне мешают, мог бы воспротивиться | злость |
| неожиданное | удивление |
| поступил против своих правил | стыд / вина |
| свой человек рядом | любовь |

Кроме отдельных чувств есть **настроение** — медленный фон (хорошо/плохо,
спокойно/возбуждённо, владею ли собой), который красит восприятие. И есть
**регуляция** — существо не просто чувствует, а управляет чувством:
переосмысливает («это не так страшно»), отвлекается, ищет утешения у папы,
подавляет (подавление стоит дорого — растёт кортизол). Это и отличает живое
существо от автомата страстей.

Чувство **окрашивает выбор действия**: страх тянет прочь, злость — навстречу,
радость — к действию, печаль ищет близости (`Emotions.bias_score`).

### 4. «Свой человек» (`core/social.py`)

Теория привязанности (Боулби, Эйнсворт): у ребёнка есть один значимый
взрослый — «надёжная база».

- **Привязанность** к папе растёт от близости и заботы — это не «цель
  go_to_player», а прочная связь.
- **Разлука** переживается: папы нет долго → растёт дистресс, хочется к нему.
- **Встреча** тем радостнее, чем дольше ждал.
- **Теория сознания** (`social.MindReading`): существо понимает, что у папы
  есть свои желания и чувства, и строит модель «чего папа хочет».
- **Просоциальность**: из любви хочется помогать и радовать папу, а не только
  выполнять команды.

### 5. Игра и воображение (`core/play.py`)

Игра — главный способ расти и радоваться. Существо **воображает** игру
«понарошку» («строю башню до неба», «скачу как зайчик», «делаю папе
сюрприз»), превращает предмет в игрушку («палка — это меч»). Играет, когда
сыт, в безопасности и в хорошем настроении; от игры поднимается дофамин.

### 6. Привычки (`core/habits.py`)

Повторяющееся поведение становится привычкой и идёт «на автомате» — это
экономит силы. Но у привычек есть тёмная сторона: они негибки. Поэтому
привычка, которая больше **не даёт результата, ослабляется и забывается**
(переучивание) — так существо не залипает на бесполезном действии.

### 7. Метапознание (`core/metacognition.py`)

Существо **думает о своём думании**: замечает, что зациклилось или перестало
понимать — и меняет подход, а не долбит одно и то же. У него есть «чувство
знания» («я знаю это» / «я не понимаю») и умение **спросить папу**, когда
непонятно. Это и есть «поумнеть» вместо «упорствовать».

### 8. Язык (`core/language.py`)

Речь растёт, как у ребёнка: лепет → слово → «телеграф» → фраза → «потому
что». Существо запоминает слова от папы, **само даёт имена** новым вещам и
**спрашивает**: «папа, а что такое дверь?».

### 9. Взросление (`core/development.py`)

Существо не остаётся одинаковым — оно **растёт от прожитого опыта**, а не по
таймеру: младенец → малыш → дошкольник → школьник. От стадии зависит длина
фразы, сила игры и любопытства, терпение и самостоятельность («я сам!»).
Возраст сохраняется — папа видит, как ребёнок взрослеет.

### Как это работает вместе

Каждый шаг существо проходит человеческий цикл:

1. **Тело** ощущает себя (`interoception`).
2. **Чувство** рождается из оценки происходящего (`emotions.appraise`).
3. **Настроение** течёт медленно и красит всё (`emotions.tick`).
4. **Привязанность** следит за папой: близость/разлука (`social.update`).
5. **Внимание** ставит чувство и телесное ощущение в фокус сознания.
6. **Решение**: если чувство сильное — сначала успокоиться; если залип —
   сменить подход; если заняться нечем — поиграть, спросить, поступить по
   привычке; иначе — дело (ремесло, план, задача игры).
7. **Речь** — по возрасту и от всего сердца, а не по шаблону.

Спросите ребёнка «как ты?» — и он ответит из живого чувства: *«папа, мне
страшно, сердце колотится»*.
